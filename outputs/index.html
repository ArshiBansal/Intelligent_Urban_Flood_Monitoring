Prototype Provenance & Operational Boundary: Precipitation calibration is fit on a reproducible sample drawn after leakage-safe partitioning of the 9,582,912-row WeatherGPT D1 corpus and evaluated against ERA5-Land reanalysis (not independent station truth). 5. Local Reproduction Commands

Run the complete pipeline from scratch in PowerShell or bash: 

# 1. Audit full 9,582,912-row dataset
python scripts/audit_dataset.py

# 2. Train and evaluate two-stage hurdle rainfall calibration models
python scripts/train_precipitation.py --max-rows 150000

# 3. Execute coupled rainfall-runoff-drainage simulations & mass balance checks
python scripts/run_flood_demo.py

# 4. Generate local interactive dashboard
python scripts/make_dashboard.py

# 5. Serve locally
python -m http.server 8000 --directory outputs
